# Module 7 WinForms demonstration

Open Modul7.sln in Visual Studio 2022 with the .NET 9 desktop workload. Choose SolarScope as startup project and run with Ctrl+F5. LabLogin is a separate classroom exercise.

SolarScope includes Home, Simulation Input, Results, Session History, Capacity Comparison, and Guide screens. Forms support Windows Forms Designer. Energy values are fixed demonstration fixtures; history lasts only for the running session. API, database, and production calculation are not integrated.

Build: dotnet build Modul7.sln

WORKSHEET_HOMEWORK_7_SolarScope.docx documents the six screens and navigation with actual screenshots. Original validation: 47 automated checks passed. Actual Windows 125% scaling remains unverified; simulated DPI notifications were tested.
